A one-page digital business card and portfolio for **Rayyan Aljamal**, a Full-Stack Developer & Website Builder based in Irbid, Jordan. Tagline: *I build websites that build your business.*

## What is inside

| File | Purpose |
| --- | --- |

The site is fully static (plain HTML, CSS, and JavaScript in single files). No build step, no dependencies to install.

## Run it locally

Open `index.html` in any browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publish on GitHub Pages

1. Push this folder to a GitHub repository (for example `rayyan-business-card`).
2. Open the repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **`main`** and folder **`/ (root)`**, then **Save**.
5. Wait a minute or two. Your card is live at `https://<your-username>.github.io/<repo-name>/`.

Share that link anywhere: WhatsApp, Instagram bio, LinkedIn, or printed as a QR code on the physical cards.

## Print the business cards

1. Open `print-cards.html` in a browser.
2. Click **Print / Save as PDF**.
3. Set scale to **100%** and margins to **None**. Cards print two per row (fronts and backs).
4. To print double-sided: print the fronts, put the sheets back in the tray, then print the backs.
5. Sending to a print shop? Save the page as a PDF and ask for **3.5 × 2in cards, 300 DPI, 3mm bleed**.

The three designs: **Dark Emerald Executive**, **Light Minimal**, and **Gradient Bold**. Every back carries the services list and the tagline.
